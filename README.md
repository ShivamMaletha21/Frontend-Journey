# She Can Foundation - NGO Landing Page
A responsive and modern NGO landing page built using **HTML5** and **CSS3**.  
This project is inspired by real-world charity websites like WishFund and focuses on clean UI design, structure, and usability.
---

##  Project Overview
This project is a frontend UI design for an NGO named **She Can Foundation**.  
It includes a professional navigation bar, contact section, social media icons, and a donation button layout.

The goal of this project is to practice **real-world website structure and UI design skills**.
---
##  Features
- Responsive top navigation bar
- Contact information section (phone & email)
- Social media icons using Font Awesome
- Donate button UI
- Main navigation menu (Home, About, Contact, Initiatives)
- Clean and modern layout
- Structured HTML & CSS code
---

## 🛠️ Tech Stack
- HTML5
- CSS3
- Font Awesome (Icons)
